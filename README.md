# Simulador de Redes Sociais

Projeto escolar que calcula o tempo gasto nas redes sociais por dia, semana e mês.

## Funcionalidades
- Informar as horas diárias de uso.
- Calcular o tempo semanal e mensal.
- Comparar o uso com uma média de referência.
- Exibir mensagens de reflexão sobre o uso das redes sociais.

## Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## Objetivo
Promover a reflexão sobre o tempo gasto nas redes sociais e incentivar o uso consciente da tecnologia.
